# 🧮 Neon Smart Calculator - Modern Math App

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://neon-smart-calculator-marcociencia.streamlit.app)

## 🚀 Features

- ✅ **Smart Evaluation** - Instantly processes complex mathematical expressions.
- 🎨 **Neon UI/UX** - Custom CSS for a sleek, responsive, and tactile button experience.
- 🧠 **Session Memory** - Utilizes Streamlit's Session State for a flawless typing flow.
- 📱 **Mobile Ready** - Beautifully adapts to desktop and mobile screens.
- 🚀 **One-Click Deploy** - Live and instantly accessible on Streamlit Cloud.

## 🛠️ Tech Stack

- **Python 3.8+**
- **Streamlit 1.28+**

## 🚀 Quick Start

```bash
git clone [https://github.com/marcociencia/Neon-Smart-Calculator.git](https://github.com/marcociencia/Neon-Smart-Calculator.git)
cd Neon-Smart-Calculator
pip install -r requirements.txt
streamlit run app.py
